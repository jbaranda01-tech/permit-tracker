Formato Esperado — Reportes

El archivo Excel debe tener las siguientes columnas en orden:

Unidad Categoría Severidad Descripción Estado Fecha Reporte Fecha Resuelto

Unidad debe ser solo el número de unidad (o la placa) de un camión existente — sin el símbolo # (ej. 204, no #204). Las filas sin coincidencia se omiten y se listan como error.

Categoría: {{ categories|map(attribute=1)|join(', ') }}.

Severidad: {{ severities|map(attribute=1)|join(', ') }} (por defecto: Media).

Estado: {{ statuses|map(attribute=1)|join(', ') }} (por defecto: Reportado). Los estados Resuelto/Cerrado usan la Fecha Resuelto.

Se acepta el nombre en español o el código interno. Fecha Reporte usa la fecha de hoy si se deja en blanco.
