Importar desde Excel

Formato Esperado — Empleados

El archivo Excel debe tener las siguientes columnas en orden:

Nombre Empleado Compañía (LB/PLI) Área Status # Licencia Exp. Licencia Endoso HAZMAT NTSP TWIC Cert. Médico Antecedentes Record Choferil Camisas HM-126 HM-232 CPR

Los empleados que ya existen (por nombre exacto) serán omitidos.

Las fechas con año de 2 dígitos (ej. 1930 → 2030) se corregirán automáticamente.

Celdas con "N/A" se marcarán como No Aplica. Celdas vacías se marcarán como datos pendientes.

Arrastra tu archivo Excel aquí o haz clic para seleccionar

Formato Esperado — Equipos

El archivo Excel debe tener las siguientes columnas en orden:

Titulo Unidad Compañía (LB/PLI/Personal) Modelo Año VIN Tablilla Seguro Marbete Inspección Voucher NTSP Costo

Se crearán hasta 4 permisos por equipo: Marbete, Inspección, Voucher y NTSP — cada uno con su propia fecha de vencimiento.

El Voucher no aplica a equipos marcados como Personal.

Equipos existentes (por VIN o tablilla) se actualizan en lugar de duplicarse.

NTSP y Costo pueden dejarse en blanco; se llenarán al re-importar el archivo más adelante.

Arrastra tu archivo Excel aquí o haz clic para seleccionar
